# Proyecto de ejemplo: viga (datos sintéticos)

Proyecto didáctico de la práctica de C2. Contiene un registro **sintético** de aceleración
(`datos/aceleracion.csv`, 2048 muestras a 200 Hz), un script de análisis en Python y un informe Quarto.

- `scripts/analiza.py`: calcula media, desviación, valor eficaz (RMS) y frecuencia dominante.
- `tests/test_analiza.py`: pruebas de `analiza.py`.
- `index.qmd`: informe (se escribe a mano en la práctica; aquí solo hay el esqueleto).
